# Getting help

1. Check the [README](README.md) for downloading, building and the keyboard
   controls.
2. Browse the [documentation index](docs/README.md).
3. Search the [issues](https://github.com/zolaski333/EngineLab/issues), open or
   closed, in case your question has already been answered.

If nothing helps, open an issue using one of the templates. Questions about how
the simulation works, engine files or exhaust designs are welcome there too.

EngineLab is maintained in spare time, so answers may take a few days.
