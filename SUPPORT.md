# Support Guide

Thank you for using EngineLab! Here is how you can find help or get support:

---

## 🔍 Search Existing Resources

Before opening a new support request, please:
1. Check the [README.md](README.md) for build requirements and keyboard controls.
2. Read the public documents in the `docs/` folder:
   - [architecture.md](docs/architecture.md) (Engine-audio architecture)
   - [realtime-audio.md](docs/realtime-audio.md) (Audio synthesizers and nodes)
   - [simulation-model.md](docs/simulation-model.md) (Physical simulator models)
3. Search the GitHub Issues section to see if your question or issue has already been discussed or resolved.

---

## 💬 Community Support

- **GitHub Issues:** Use issues for reporting bugs, requesting features, or asking technical questions about the simulator mechanics.
- **Discussions:** For general questions, setup advice, or sharing your custom JSON/YAML engine presets, feel free to use the Discussions section of the repository (if enabled).

---

## 🛠️ Commercial & Professional Support

EngineLab is currently maintained as an open-source project. For professional integration requests, custom physical models, or specialized licensing questions, please contact the repository administrator.
