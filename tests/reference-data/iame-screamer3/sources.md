# IAME Screamer III 125 cm³ (KZ, six-speed): reference data

## Source

CIK-FIA homologation form 040-EZ-24 (IAME "Screamer 3"), as published by
the Brazilian confederation (cba.org.br). Every number below is read from it.

## Engine

- Bore 54.00 mm (54.08 max), stroke 54.40 mm, rod 110 mm; swept 124.59 cm³;
  water-cooled; 5 transfer ports in the cylinder, 3 transfer ducts in the
  crankcase; a spherical chamber with a squish band.
- Port opening angles: "according to the regulations" (not on the form).
- Gearbox: primary 19/75; ratios 13/32, 16/29, 18/27, 22/27, 22/23, 26/24.
- Reed: the form draws only the cover's outline.

## Blocker

No absolute power curve of the Screamer III is public: Ortenzi & Bossaglia
(Energies 16, 4947, 2023, their Fig. 16) show the KZ curve normalised only,
the maker's data being confidential. Without the port timings and a measured
curve in physical units, this engine cannot be validated absolutely; only a
shape comparison against a normalised curve is possible, and its port
timings would have to be assumed.
